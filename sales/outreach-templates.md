# MarkLabs — Шаблони повідомлень для пошуку клієнтів

## 1. Перший контакт (Instagram DM)

### Варіант A — Комплімент + Пропозиція
```
Привіт! 👋

Побачив ваш бізнес в Instagram — виглядає круто.
Помітив що у вас немає сайту (або сайт міг би працювати краще).

Я — Марко, займаюсь створенням сайтів для малого бізнесу.
Можу показати як виглядатиме ваш сайт — безкоштовно, без зобов'язань.

Цікаво?
```

### Варіант B — Конкретна цінність
```
Добрий день!

Бачу що ви активні в Instagram — класний контент.
Є ідея як перетворити ваших підписників в клієнтів через сайт.

Роблю це для бізнесів вашої ніші.
Ось приклад: [посилання на кейс]

Якщо цікаво — можу розповісти деталі.
Марко, MarkLabs Agency.
```

### Варіант C — Прямий підхід
```
Привіт! Я створюю сайти для [тип бізнесу].

Ось що зробив для схожого бізнесу: [посилання]

Можу зробити подібне для вас за 2-3 тижні.
Перша консультація безкоштовна.

Зацікавило?
```

Розумію що зайняті — якщо буде час, буду радий обговорити.
Без тиску 🙌

### Через 7 днів:

## 3. Відповіді на заперечення

### "Дорого"
```
Розумію. Давайте так: я покажу що саме отримаєте.
Після цього вирішите чи воно того варте.
Часто сайт окупається за 1-2 місяці через нових клієнтів.
```

### "Мені не потрібен сайт"
```
Окей, не питання!
А якщо б сайт приводив вам 5-10 клієнтів на місяць додатково — було б цікаво?
Просто як інструмент, який працює 24/7.
```

### "Вже є сайт"
```
Круто! А він приносить заявки?
Якщо хочете — можу безкоштовно глянути і сказати що можна покращити.
Без зобов'язань.
```

### "Подумаю"
```
Звичайно, без поспіху.
Залишу посилання на наші роботи — подивіться коли буде час:
https://www.mark-labs.com.ua

Якщо будуть питання — пишіть.
```
